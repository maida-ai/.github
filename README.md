# Maida organization profile infrastructure

This repository publishes the public [Maida.AI organization profile](profile/README.md) and owns its published product language alongside [maida/README.md](https://github.com/maida-ai/maida/blob/main/README.md).

Maida checks agent changes before merge. The product lives in [maida](https://github.com/maida-ai/maida), the canonical runnable experience in [maida-tutorials](https://github.com/maida-ai/maida-tutorials), and the GitHub boundary in [maida-assert](https://github.com/maida-ai/maida-assert). This repository is public infrastructure.
